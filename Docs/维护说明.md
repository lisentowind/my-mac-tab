# MyMacTab 维护说明

## 功能入口

- 菜单栏入口和应用生命周期：`MyMacTab/MyMacTabApp.swift`
- 全局快捷键：`MyMacTab/GlobalHotKey.swift`
- 窗口缓存、选择和浮层管理：`MyMacTab/WindowManager.swift`
- 后台 Accessibility 批量读取、聚焦、最小化和分屏：`MyMacTab/AccessibilityReader.swift`
- 圆环与 Dock 窗口列表界面：`MyMacTab/WindowRingView.swift`
- Dock 图标悬停检测：`MyMacTab/DockHoverController.swift`
- 权限状态和设置说明界面：`MyMacTab/ContentView.swift`
- 系统版本、玻璃材质与辅助显示设置适配：`MyMacTab/AdaptiveWindowSurface.swift`

## 窗口环

窗口环使用 860×520 点透明面板：左侧应用环直径 416 点、轨道半径 157 点，右侧列表矩形为 (474, 66, 360, 386)。保留蓝色玻璃材质、环形应用图标、红色窗口数量角标与中心应用名，移除窗口扇片及其分页和动画代码。应用图标尺寸随数量收缩；鼠标悬停或点击选择应用，键盘同样可切换。列表滚动显示全部窗口，标题最多两行，完整标题通过 help 查看，选中行使用蓝色边框。头部提供窗口计数和上一个/下一个按钮，底部按配置显示快捷键。

`WindowRingGeometry` 统一定义面板、圆心和列表矩形，`WindowManager.isRingContentPoint` 与绘制共用几何。圆环、右侧列表和关闭按钮属于内容，其余透明区域点击关闭。屏幕不足时整体等比缩小，事件命中按同一比例换算。窗口切换后滚动到选中行，不为键盘滚动添加动画。键盘选择后记录鼠标坐标，防止静止指针引发 hover 回跳；实际移动后恢复悬停选择。减少动态效果时取消图标弹簧。

环带命中按角度计算：`applicationHitRange(count:)` 给出图标轨道两侧留有富余的内外半径，本地点击监听到环带内的按下后，直接用 `atan2` 换算角度取最近的应用，并吞掉该次按下与抬起事件，避免 SwiftUI 按钮与命中判定各执行一次。图标本身另有 `iconHitPadding` 的透明留白，视觉尺寸不变。点击环带不会关闭浮层。

玻璃背景 `AdaptiveWindowSurface` 带 `allowsHitTesting(false)`，圆环内空白处 SwiftUI 的命中测试会返回 nil；borderless 透明窗口在 hitTest 为 nil 时会把事件转给下层窗口，表现为滚轮和点击穿透到后面的应用、面板随之失去键盘焦点。面板内容因此包一层 `RingContentView`，`hitTest` 在子视图未命中时返回自身：SwiftUI 内容仍优先响应，其余空白区域由我们接管，滚轮、点击和快捷键都不会再漏出去。

滚轮由本地 `.scrollWheel` 监听处理：指针在右侧列表内时原样放行，列表保持自身滚动；在环上时按滚动意图切换应用，正值选中上一个、负值选中下一个。触控板/妙控鼠标用 `phase` 划分手势，一次手势只切一个应用：首个非零位移立即生效并锁住，手势结束或停顿超过 `RingScrollTuning.gestureIdleTimeout`（250ms）后才接受下一次手势；抬手后的惯性阶段直接吞掉，不追加切换。鼠标滚轮没有 `phase`，每个事件就是一格，逐格切换；没有 `phase` 的高精度滚轮也按事件处理。这样慢速滑动不会因位移不足被丢弃，快速甩动也不会在一个手势内一次跨过多个应用。灵敏度只需调整 `RingScrollTuning`。

`RingPanel.sendEvent` 根据 `ShortcutConfiguration` 匹配按键，再调用 WindowManager 的应用、窗口导航、激活、最小化/恢复、关闭和分屏操作，不依赖 SwiftUI 固定 onKeyPress。呼出时冻结应用顺序，窗口缓存、AX 身份与操作流程沿用既有实现。

呼出时先激活应用再 `makeKeyAndOrderFront`，随后在 40ms 间隔内最多重试 6 次确认 `isKeyWindow`：accessory 应用从其他前台应用切回来是异步的，紧接着调用 makeKey 时系统可能还没完成激活。与此同时，圆环显示期间额外安装一个可吞键的 `PreviewKeyboardMonitor`，与面板共用 `handleRingShortcut`，因此即使面板暂时没拿到键盘焦点，方向键、回车和 Esc 仍然生效，按键也不会漏到下层应用。tap 在浮层关闭后的下一轮 runloop 才失效，避免在它自己的回调里停掉自身；关闭后 `handleRingShortcut` 通过 `ringRequested` 早退。

## 自定义快捷键

`ShortcutConfiguration.swift` 定义动作及默认组合，使用物理 keyCode 与 Command/Control/Option/Shift 四种修饰键匹配，忽略 Caps Lock、Fn 和数字键盘标记；按键名称从当前键盘布局读取。以 `shortcuts.bindings` 保存配置，菜单、窗口环和 Dock 提示同步读取配置。窗口环、菜单、Dock 列表分别匹配；与同作用域或全局呼出重复的组合拒绝保存。原生 Command-Tab 不重映射，系统自己的快捷键占用不能完全预先检测。

设置增加「快捷键」标签页，点击按键区域后录入组合；录入期间取消 Carbon 全局注册并通过本地键盘监视捕获按键，完成、失焦或离开页面后恢复注册。全局呼出和菜单组合需要修饰键，提供恢复默认按钮，注册失败显示状态码。`GlobalHotKey.register` 接收配置并报告注册结果。设置和退出为应用菜单范围，并非全局拦截。

Dock 列表的方向键、Tab/Shift-Tab 备用选择、回车和数字键盘回车、关闭、退格与向前删除均为配置项；增加最小化/恢复、关闭选中窗口和编辑筛选的组合。非激活列表仍只在指针位于面板时处理快捷键，搜索编辑时由面板匹配自定义组合，并在输入法组合期间放行。搜索框中的原生文本编辑保留；删除键编辑时交给原生输入控件。

## Dock 预览

预览每次打开时按应用名和最长窗口标题测量宽度，限制在 248–320 点之间，并受屏幕可用宽度约束；显示期间固定宽度，避免焦点通知和鼠标移动反复测量或改变列表位置。长标题保留首尾，完整标题通过提示查看。鼠标与键盘共用选中状态，选中行使用不透明的系统选中背景色与白色文字/图标。当前窗口用勾选图标与状态文字区分；悬停/选中时显示独立的最小化或恢复、关闭按钮，预留固定按钮空间，标题不跳动。窗口行高 50 点、行间距 6 点，左侧使用无底座的状态符号；主操作区不单独绘制边框或高亮，整行只有一层选中背景。右侧操作按钮保留 28×28 点命中区，默认仅显示图标，悬停时才出现轻底色，关闭按钮悬停使用红底白字；标题与操作区之间保留 16 点留白。面板默认不成为 key/main window，不夺走目标应用焦点；显式点击搜索框时才允许非激活面板成为 key window，为原生输入法提供焦点。点击前重新读取焦点和最小化状态：前台已聚焦且未最小化时最小化，否则取消隐藏、激活并恢复该窗口；连续点击按顺序执行，完成后重新读取列表和状态。最小化属性设置失败时尝试辅助功能最小化按钮，不支持窗口控制的应用仍受系统辅助功能限制。

`DockHoverController` 使用全局/本地鼠标事件合并更新（最多每 1/60 秒一次）；远离屏幕的 Dock 边缘且没有预览时，普通鼠标移动直接返回，不扫描辅助功能树。保留一个 1 秒、容差 250ms 的坐标和权限补查，兼容 accessory 应用偶尔漏收的全局事件。屏幕矩形、应用 bundle identifier / 路径 / 名称索引仅在屏幕和应用生命周期变化时重建，不随鼠标移动枚举所有应用。

鼠标进入 Dock 附近后才异步读取 Dock AX 树，普通移动最短间隔 400ms，鼠标按下或菜单打开期间 120ms；Dock 放大结束、鼠标稳定且没有菜单后停止连续扫描。菜单和名称气泡的 AX 通知会触发更新，不支持这些通知的系统仍由鼠标事件和补查兜底。Dock 扫描在独立 actor 中串行运行，支持取消、请求代次检查、80ms 消息超时、最多 160 节点及 8 层深度限制；位置、尺寸等属性批量读取，应用图标内部子树不继续递归。Dock 重启、屏幕改变、休眠和会话失活会使旧任务失效。

命中图标后优先按 bundle identifier，其次按 URL 路径，最后按名称匹配运行中的应用。窗口列表使用 1 秒缓存：有缓存立即显示，过期后在后台更新；空窗口结果也缓存，避免无窗口应用被反复读取。快速 hover 取消旧请求，旧结果不能覆盖当前应用。图标命中优先于预览缓冲区，动画期间也可切换应用；Dock 放大改变图标矩形时同步更新预览锚点。离开 Dock 与预览后使用单次 180ms 延时关闭，相邻图标之间的短间隙不立即关闭。从图标到预览有窄的命中通道，允许穿过原生名称提示的留白区域。点击窗口行会聚焦该窗口；再次点击已聚焦窗口会最小化它。

若 macOS 改变 Dock 的 AX role 或树结构，应检查 `DockAccessibilityReader` 的节点筛选。名称气泡通过 `AXHelpTag` 及相关 subrole 读取，菜单和子菜单通过 `AXMenu` / `AXShownMenuUIElement` 读取；同时检查顶层 `AXWindows`，兼容不把提示放在 children 中的 Dock 版本。

预览使用低于 Dock 和系统菜单的 `.floating` 层级。底部 Dock 的图标与预览之间预留 52 点供原生名称、箭头和阴影显示；左右 Dock 按应用名称估算提示宽度。菜单和名称气泡分别传入 `DockPreviewPlacement`：右键菜单出现后，预览与主菜单左边缘对齐，直接定位到菜单和子菜单顶部上方 12 点处；停止已有位移动画，子菜单展开时只调整避让高度，不改变横向对齐基准。Dock 扫描先记录主菜单矩形，再读取子菜单，避免向左展开的子菜单改变对齐位置。位置限制在当前屏幕可用区域内，顶部空间不足时贴住可用区域顶部。仅名称气泡出现时保留原有的候选位置避让逻辑。菜单操作期间保持当前应用预览，名称气泡不会锁住 hover；菜单关闭后恢复原始位置及正常离开关闭逻辑。

名称气泡避让、恢复原位和跨图标切换共用 `CADisplayLink` 临界阻尼弹簧，在 common run-loop mode 中插值 x、y、宽、高；目标改变时保留当前位置和速度。只有移动期间创建显示链接，到位或关闭即销毁；刷新率最高跟随屏幕到 120Hz，低电量模式最高 60Hz。只有位置变化时使用 `setFrameOrigin`，避免无意义的尺寸布局。首次直接定位，已有面板在无菜单时平滑移动和变高，内容用 160ms 淡入淡出。`NSHostingView.sizingOptions = []` 且根视图随面板伸缩，避免 intrinsic size 抢先改变大小。“减少动态效果”开启时直接定位。呼出圆环时停止 Dock 扫描和预览，圆环关闭后恢复检测。

## 原生 Command-Tab 预览

`SwitcherKeyboardMonitor` 使用 listen-only CGEvent tap 观察 Command-Tab、Command 松开与 Escape，不吞掉原生快捷键。`DockHoverController` 的本地/全局 NSEvent 观察同时作为补充；tap 不可用时，按住 Command 移动鼠标也会尝试探测。键盘观察与 Dock 控制器共同启动和停止，无辅助功能权限时不安装 tap。

Command-Tab 开始一个独立的原生切换会话，清除旧 Dock 悬停请求。仅在该会话期间，每 120ms 按需读取 Dock 中的 `AXProcessSwitcherList`（role/subrole）或 `AppSwitcherIdentifier` 容器，并从子节点的 identifier、URL 或唯一应用名称匹配 PID。不按 MRU 顺序、屏幕像素或固定图标间距猜测应用。扫描上限为 240 个节点、10 层深度，每条 AX 消息仍为 80ms；未识别到切换器时 1.5 秒后停止探测。尚未接管预览时，Command 松开或 Escape 会关闭预览；原生容器消失、休眠、切屏或权限撤销也会取消旧任务与预览。

每个切换器图标保存自身容器矩形，以便多屏上选择对应的预览位置。窗口列表和缩略图使用 popUpMenu + 1 层级，列表直接定位到容器上方或下方，并根据可用高度缩短滚动区域；空间不足容纳一个窗口条目时不展示。原生容器作为缩略图的额外避让区域。普通 Dock 入口继续使用 floating 层级和原有弹簧定位。

鼠标进入实际预览面板时，由控制器按屏幕坐标主动接管，不依赖系统切换器放行 hover 或 mouseDown；图标到面板的缓冲通道不触发接管。停止原生会话扫描，发送一对带独立标记的 Escape 事件取消系统当前选择，但保留窗口列表。Command 松开事件到达时也补做面板命中，避免鼠标移入与松键的事件先后造成误关闭。该标记让 `PreviewKeyboardMonitor` 放行这对取消事件，避免误关闭自己的预览。窗口操作及搜索焦点在取消事件发出后至少等待 60ms；缓冲后补送一次本地 mouseMoved 更新行高亮和长悬停，避免指针静止时不刷新。鼠标点击、辅助功能操作仍可作为接管补充入口。接管后可以松开 Command 查看缩略图、使用搜索和其他窗口操作；离开列表仍使用原有延迟关闭逻辑。鼠标没有进入预览时，松开 Command 正常执行系统应用切换。实际原生退出、点击和焦点行为需本机验证。

全局预览开关和按应用排除同时作用于 Dock 和原生入口；`preview.switcher` 单独控制原生入口，默认开启。系统没有切换器扩展接口，AX 结构变化可能导致此入口无法识别，不能把类型校验当作原生交互兼容性验证。

## 长悬停缩略图、窗口操作与偏好

`PreviewPreferences` 使用 UserDefaults 保存全局预览开关、首次显示延迟（默认 150ms，可调 0–800ms）、缩略图开关、长悬停时间（默认 450ms，可调 250–1200ms）、缩略图尺寸及按应用的排除列表。缩略图默认关闭，由用户在“设置 → 窗口预览”开启。相邻 Dock 图标切换不重复等待首次显示延迟。应用排除按 bundle identifier 保存，无 bundle identifier 时使用应用路径；未运行的排除项也可重新开启。全局或按应用关闭不影响快捷键圆环。

`WindowThumbnailPresenter` 在独立的非激活浮层中展示缩略图，优先出现在列表右侧，其次左侧或上方；不挤宽主列表，不遮挡已检测到的原生菜单或名称提示。空间不足时不提交截图。移入缩略图的间隙有命中缓冲，离开行时检查行身份，避免旧行的离开事件取消新行请求；切换应用、筛选、操作窗口或关闭列表时取消旧请求。位图用短淡入显示，并遵循减少动态效果；材质复用系统玻璃/毛玻璃与辅助显示设置。

`WindowThumbnailReader` 使用 macOS 14 起可用的 ScreenCaptureKit 单次截图接口，不创建持续 SCStream、不轮询截图、不写入磁盘，也不使用私有窗口编号 API。只对当前停留的窗口请求画面；以 PID、AX 几何及唯一标题对应 SCWindow，对应关系含糊时显示不可预览状态。系统单次截图串行提交，旧请求即使已进入系统截图阶段，其结果也会在取消或代次变化后被丢弃。输出最大约 672×420 像素，3 秒内复用截图；最小化窗口仅使用 60 秒内的已有缓存，并标注“上次预览”，没有缓存时使用明确的占位状态。

截图使用 NSCache，成本预算 8MB、最多 12 张，允许系统在内存压力下提前驱逐。停止使用 60 秒后清理，关闭相关偏好、应用退出、休眠或会话失活时立即发起清理；NSCache 预算仅针对保存的位图，不能代表整个进程的内存上限。

窗口使用顺序仅在内存保存。只为当前前台应用注册 AXFocusedWindowChanged/AXMainWindowChanged 通知；已知窗口的焦点变化只读取 AXFocusedWindow，不重新枚举所有窗口标题。首次遇到新窗口时才补读列表。预览/圆环显示期间保留已有窗口顺序，新窗口追加，选中窗口按 ID 保持；下次打开按最近使用顺序排列。应用退出清理顺序记录，旧观察任务通过代次隔离，不能覆盖新应用的观察器。

Dock 列表支持上下键或 Tab 选择、回车打开、Esc 清除筛选或退出、直接输入标题筛选。PreviewKeyboardMonitor 仅在列表可见时安装事件 tap，指针位于列表/缩略图且没有原生菜单时才处理按键；组合快捷键原样放行，关闭列表移除 tap。若系统不允许安装 tap，仍可点击搜索框使用原生键盘浏览。搜索框使用 NSSearchField，支持中文组合输入和候选词；编辑期间保留列表，Esc 或点击外部结束操作。键盘滚动或筛选期间忽略静止指针引发的 hover，实际鼠标移动后恢复鼠标选择；滚动跟随选中窗口且不添加键盘滚动动画。

整行点击保持“当前前台窗口最小化，其余打开/恢复”的行为；独立按钮明确执行最小化/恢复或关闭。关闭通过目标窗口的 AXCloseButton 执行，保留应用自己的未保存确认。操作串行执行并读取新状态；休眠、退出及其他需要取消操作的路径使用代次使排队的旧操作失效。可访问性提供窗口状态和命名操作。圆环和 Dock 列表共用窗口选择，圆环保留现有外观与键盘交互，并补齐设置中说明的 Option+左右分屏快捷键。

## 性能与窗口缓存

窗口标题优先读取 `AXTitle`；空白或通用占位标题再尝试标题控件、文档文件名和非通用的辅助功能描述。不递归扫描窗口内部、不截屏。仍没有可用标题时保留原窗口，以“应用名 · 未命名窗口 N”显示，最小化时补充状态；通过 AX 元素身份复用编号，避免窗口枚举顺序改变后编号跳动。无标题不等于无效窗口，不直接删除或按标题合并，避免漏掉自绘界面或真实窗口。

`refreshPermission()` 仅检查权限，不枚举窗口。`refreshWindows()` 由呼出圆环按需发起，同一时间只允许一个刷新任务，使用缓存先显示；每个应用读取一次 `AXWindows`，每个窗口批量读取标题和最小化状态。读取和窗口控制共用 `WindowAccessibilityReader` actor，100ms 消息超时；无响应的目标应用不会阻塞主线程动画。关闭圆环即取消尚未完成的枚举，取消或过期任务不能重新打开浮层。

应用分组、排序和 ID 查找表只在窗口数据变化时构建，SwiftUI body 不再反复分组排序。窗口身份通过 AX 元素相等性复用，不使用易随窗口关闭而变化的数组序号。没有内容变化时不重复发布列表；重复选中同一窗口也不发布更新。圆环显示期间固定呼出前的前台应用排序。应用退出清除相应窗口、时间戳和图标缓存；休眠或会话失活时取消后台读取与窗口操作、隐藏浮层。

每个应用仅保留一份 192px 图标位图，满足当前最大图标的 Retina 显示尺寸；无窗口应用不保留图标。Dock 列表使用 `LazyVStack`，鼠标和键盘复用统一选中状态。缩略图状态由独立 presenter 发布，不会在画面返回时刷新窗口列表；未改变的过滤结果不重复发布。应用环与右侧列表使用 AdaptiveWindowSurface，图标底座使用普通透明色，不为每个图标单独建立模糊层。关闭浮层后保留轻量 NSPanel，释放 NSHostingView 及其玻璃材质视图。菜单栏根 Scene 不订阅窗口选择的每次变化。

切换窗口时先激活所属应用，再在后台恢复、设为 focused/main 并执行 `AXRaise`。窗口位置及 Dock 图标位置来自 Accessibility API，原点在左上；AppKit 屏幕坐标原点在左下，以主屏顶部统一转换多显示器坐标。分屏使用目标屏幕的 `visibleFrame`，避开菜单栏和 Dock。

## 应用图标

`MyMacTab/Assets.xcassets/AppIcon.appiconset` 已配置 macOS 全部 10 个槽位，PNG 实际像素覆盖 16、32、64、128、256、512、1024。图标由用户提供的 JPG 保留构图缩放，加入透明留白和圆角；`Contents.json` 引用对应文件，Xcode 的 `ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon` 会自动生成应用图标，不需要手动拖入每个槽位。

## 权限与系统限制

最低运行版本为 macOS 14。Dock 预览、应用环和右侧列表共用 `AdaptiveWindowSurface`：macOS 26 及以上使用原生 `.glassEffect(.regular)`，macOS 14/15 回退到 `.regularMaterial`；不自行模拟液态玻璃。透明度和增强对比度的辅助显示设置优先，启用时使用实色背景及清晰边框；关闭后恢复系统材质。Dock 使用系统中性色，圆环保留蓝色调。界面不展示品牌标题，设置页与菜单栏入口使用功能名称。

运行时需要在“系统设置 → 隐私与安全性 → 辅助功能”允许 MyMacTab。项目关闭 App Sandbox，因为沙盒会限制读取和控制其他应用的窗口。

macOS 没有公开 API 可以可靠枚举和管理所有 Spaces。Accessibility 通常能列出目标应用公开的窗口；聚焦其他桌面的窗口会交由系统切换 Space，但结果受目标应用和系统当前状态影响。部分应用不暴露标准 AX window，受保护内容也可能无法读取或控制。窗口标题列表与窗口控制仅需要辅助功能权限。可选的窗口缩略图需要额外的屏幕录制权限；未授权时显示应用图标和权限说明，不影响窗口操作。权限请求只由设置中的“允许…”按钮发起，悬停和应用启动都不会请求授权。

## 校验

在项目根目录执行 Swift 类型校验：

```sh
swiftc -typecheck -default-isolation MainActor \
  -module-cache-path /tmp/MyMacTab-swift-module-cache \
  -sdk /Applications/Xcode.app/Contents/Developer/Platforms/MacOSX.platform/Developer/SDKs/MacOSX.sdk \
  -target arm64-apple-macosx14.0 \
  MyMacTab/*.swift
```

由用户在 Xcode 中使用 `MyMacTab` scheme 和 `My Mac` 运行目标进行本机交互验收。性能优化目前通过代码检查和类型校验，未启动应用进行 CPU、内存或帧率采样，不应据此声称具体占用或帧率。

界面验收时，检查应用环与右侧列表是否完整、多个窗口悬停时位置是否稳定，以及点击列表能打开窗口、点击透明间隙能关闭浮层。另外检查长悬停与快速划过、缩略图权限拒绝/允许、最小化缓存、同名窗口、输入法候选词、键盘滚动、关闭未保存文档、应用排除持久化、多屏边缘及系统减少动态效果/透明度设置。类型校验不能代替这些本机鼠标、焦点和截图验证。
